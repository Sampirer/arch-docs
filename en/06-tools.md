# Tools

> Rofi, Dunst, Picom and more.

---

## Rofi – App Launcher

| Keybinding | Function |
|------------|----------|
| `Super + R` | Launch programs |
| `Super + Tab` | Switch windows |

---

## Dunst – Notifications

```bash
notify-send "Test" "Message"
pkill dunst && dunst &
```

---

## Picom – Compositor

Shadows, transparency, blur.

```bash
pkill picom && picom &
```

---

## Feh – Wallpaper

```bash
feh --bg-fill ~/Pictures/wallpapers/image.jpg
```

---

## Flameshot – Screenshots

`Print` key

---

## Brightnessctl

```bash
brightnessctl set +10%
brightnessctl set 10%-
```

---

## Pavucontrol – Audio

```bash
pavucontrol &
```
